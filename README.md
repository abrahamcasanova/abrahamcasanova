### What I'm building

**[Meeseeks Hive](https://github.com/abrahamcasanova/meeseeks-hive)** — Autonomous AI agent swarm that generates, executes, and evolves code strategies in real time. Agents compete, learn from each other, and visualize their lifecycle in a 3D isometric office.

**[@meeseeks-sdk/core](https://www.npmjs.com/package/@meeseeks-sdk/core)** — Standalone quality gate for LLM-generated code. Sandbox execution, 0-10 scoring, SQLite memory. Works with Claude, GPT-4, Bedrock, Ollama.

**[@meeseeks-sdk/mcp](https://www.npmjs.com/package/@meeseeks-sdk/mcp)** — MCP server that makes Claude Code verify its own code before writing it to your project.
